Usage
=============

Input Preparation
-------
SHI-match requires :math:`C_\alpha`,  :math:`C_\beta`,  :math:`S_{bf}`,  :math:`F_\alpha` and :math:`F_\beta`
from unrestricted calculations. The easiest way to obtain these is to use Gaussian or NWChem to generate
file47 format (GENNBO). Otherwise, you can modify the code to read your input matrices.

Gaussian
~~~~~~~~~~

The typical input for Gaussian looks like this::

    %chk=molecule.chk
    # method/basis_set pop=NBORead

    Molecule

    1 2
    #your input geometry

    $NBO BNDIDX ARCHIVE FILE=molecule.gen $END
    eor

It is recommended that you save checkpoint files (%chk) for each calculation. SHI-match will also
support to visualize the results using formatted checkpoint (fch or fchk files are generated by :command:`formchk` command).


NWChem
~~~~~~~~~~

The typical input for NWChem looks like this::

    echo
    start molecule

    charge 1

    geometry units angstroms print xyz
    # your input geometry
    end

    basis spherical
    * library basis_set
    end

    dft
    odft
    mult 2
    xc method
    end

    property
    nbofile 1
    end

    task dft property


The ``nbofile 1`` option generates a file named :file:`molecule.gen`. The filename depends on the input specified after ``start``.

Running SHI-match
-------

Quick Start
~~~~~~~~~~

With previous input files, SHI-match can be executed as follows ::

    shi-match.py <file47>

The output will be saved in :file:`shi_match.log`.

To specify hardware you want to use, you can run with ``-hw`` or ``---hardware`` option ::

    shi-match.py <file47> -hw <hardware>

Accpetable hardware options are: ``cpu``, ``cuda`` (NVIDIA GPU), ``rocm`` (AMD GPU) and ``tpu``. The default is ``cpu``.

Gaussian cube
~~~~~~~~~~

To visualize transformed orbitals, you can run with ``-gaussian`` or ``-fch`` or ``-fchk`` or ``-g16`` option ::

    shi-match.py <file47> -gaussian molecule.fchk

SHI-match will generate a new file named :file:`transformed.fchk` that can be viewed with Avogadro or other tools.

NWChem cube
~~~~~~~~~~

To visualize transformed orbitals, you can run with ``-nwchem`` or ``-ascii-movecs`` option ::

    shi-match.py <file47> -nwchem <scf_ascii_file>

This ASCII file can be obtained with the mov2asc tool located in $NWCHEM_TOP/contrib/mov2asc.

To get the number of basis functions, you can run:

    grep "AO basis - number of functions" <nwchem_output>

Then, ASCII movecs can be prepared by: ::

    mov2asc <num_basis> <movecs_file> <ascii_file>

SHI-match will generate a new file named :file:`transformed_orbitals.ascii`. This file can be converted back to NWChem movecs format using the ``asc2mov`` tool: ::

    asc2mov <num_basis> transformed_orbitals.ascii transformed_orbitals.movecs

Using dplot tool (See more: `dplot <https://github.com/jautschbach/nwchem-dplot-utility>`_), you can create cube files by re-running NWChem with new movecs files.
